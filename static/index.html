OpenTubeX Arch repository

Arch Linux and Arch Linux ARM packages for OpenTubeX, built for x86_64 and aarch64.

Install

Download the signing key and check its fingerprint:

curl -fsSL -o opentubex.asc https://arch.opentubex.org/opentubex.asc
gpg --show-keys --fingerprint opentubex.asc

It must match:

4A60 0616 2524 0FB5 6569  221B 4672 DA44 5C55 F193

Import and trust the key:

sudo pacman-key --add opentubex.asc
sudo pacman-key --lsign-key 4A60061625240FB56569221B4672DA445C55F193

Add the repository:

grep -qxF '[opentubex]' /etc/pacman.conf || sudo tee -a /etc/pacman.conf >/dev/null <<'REPO'

[opentubex]
SigLevel = Required DatabaseRequired
Server = https://arch.opentubex.org/$repo/$arch
REPO

Install OpenTubeX, or update it with the rest of your system:

sudo pacman -Syu opentubex

Nightly builds

To follow development snapshots, trust the same signing key and add the nightly repository instead. It also receives stable releases. If /etc/pacman.conf already has an [opentubex] section, remove it first, or pacman keeps installing the stable package. 

grep -qxF '[opentubex-nightly]' /etc/pacman.conf || sudo tee -a /etc/pacman.conf >/dev/null <<'REPO'

[opentubex-nightly]
SigLevel = Required DatabaseRequired
Server = https://arch.opentubex.org/$repo/$arch
REPO
sudo pacman -Syu opentubex

AUR

OpenTubeX is also available in the AUR as opentubex, opentubex-bin, opentubex-nightly-bin, and opentubex-git. Installing opentubex from this repository replaces any of them.

Manual downloads

You can also download the x86_64 .pacman file directly from GitHub Releases and install it with sudo pacman -U. Manual installs are not tied to this repository, so they do not receive automatic updates through pacman.
